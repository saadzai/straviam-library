## Product Vision

A simple system that lets our department library keep track of its books, its members and who has borrowed what.

## Definition of Done

- All acceptance criteria are met.
- Code is merged into main through a Pull Request.
- Another developer reviews and approves the PR.
- PR closes the related issue.
- Program runs using `python main.py`.
- Unit tests pass.
- Product Owner accepts the story.
